# createDoc Tool Usage

## Purpose
The `createDoc` tool creates a new blank document with a title and optional initial content. It is specifically designed for document creation.

## When to Use createDoc vs writeDoc
- **Use createDoc when**: Creating a new document from scratch. This is the standard way to create documents.
- **Use writeDoc when**: You need to either create a new document or overwrite an existing one using the same function.

## Parameters
- `title` (required): The document title. Will default to "Untitled" if not provided.
- `content` (optional): The initial markdown content for the new document. Can be left empty to create a blank document.

## Best Practices
- Provide a descriptive title that helps users find the document later
- For documents with substantial initial content, include it in the `content` parameter
- For iterative document building, create with a title first, then use `editDoc` to add content section by section

## Important
- Every create operation creates a **pending change** that the user must approve.
- The new document's ID is generated during creation and returned in the result metadata.
- Use `listDocs` or `searchDocs` to find the document ID after creation.
- To add content incrementally, use `editDoc` after the document is created.
